# Buried Sharpshooter Practice (BO2 Zombies, Plutonium)

Practice the last step of the Buried easter egg from anywhere.

## Install
Put `Sharpshooter_Practice.gsc` in:
%localappdata%\Plutonium\storage\t6\raw\scripts\zm\

## Use
- Hold USE (interact) for about 1 second to start sharpshooter from anywhere
- Everyone spawns with MP5 + PDW and max points
- All doors open, all barriers and Leroy barricades removed, no zombie spawns
- Adjustable hud target counter

## Chat commands
- 1p / 2p / 3p / 4p: set targets to 20 / 39 / 61 / 84
- 0p or reset: default for current player count
- speed: toggle Speed Cola (for yourself)
- help: list commands
